# Submission checklist

The repository now contains evidence for the code and group-report rubric.
Complete the items marked **manual** before submission; they cannot be
truthfully generated from code.

## Group evidence

- [x] Problem framing canvas
- [x] Workflow diagram
- [x] Decision log
- [x] Data dictionary and data-quality audit
- [x] Reproducible EDA insight log and figures
- [x] Leakage-safe preprocessing and feature-engineering strategy
- [x] Baseline and alternative model comparison
- [x] Training-only cross-validation and hyperparameter tuning
- [x] Untouched test-set evaluation
- [x] Residual and feature-importance diagnostics
- [x] Recommendation and limitations
- [x] Dataset source and SHA-256 fingerprint
- [ ] Manual: verify the three-minute demo video shows the same workflow and metrics
- [ ] Manual: complete and approve the AI-use transparency statement
- [ ] Manual: check that every notebook runs from the documented working directory
- [ ] Manual: add group member responsibilities and final report page references

## Individual evidence

- [ ] Manual: each member completes a separate personal learning journey
- [ ] Manual: each member states their actual contribution and evidence

## Claims to avoid

- Do not call the main model a pre-assessment or early-intervention model.
- Do not claim that a feature causes a higher or lower grade.
- Do not present the test-set result as a guaranteed future performance.
- Do not use a prediction as the sole basis for grading, exclusion or
  disciplinary action.
