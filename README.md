# Machine-Learning-Assignment
At-Risk Student Identification (Binary Classification Lens)

What it is: Classifying students into binary categories—such as "At-Risk" (G3 < 10) versus "Safe/Passing" (G3 >= 10)—to flag students heading toward failure. 

ML Task & Models: Classification algorithms like Logistic Regression, Decision Trees, Random Forest, or Gradient Boosting.

Evaluation Metrics: Recall, Precision, F1-Score, and ROC-AUC (where maximizing Recall is crucial to avoid missing any failing students).

Business Value: Directly triggers urgent, proactive interventions like mandatory tutoring, academic counseling, or parental check-ins before a student drops out or fails
